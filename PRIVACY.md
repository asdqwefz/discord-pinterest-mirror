# Privacy Policy — crowneswensia discord mirror

Last updated: 2026-09-29

This app performs personal automation: it mirrors photos from the user's own Discord channel to the user's own Pinterest board.

- Data collected: Discord image URLs, Pinterest board IDs, OAuth tokens provided by the user.
- Storage: tokens and IDs are stored locally in the user's own `.env` file. No server, no database.
- Sharing: no data is shared with third parties. Pinterest API is called only to list boards and create pins on behalf of the user.
- Contact: open an issue in this repository to request deletion help.

Türkçe: Bu uygulama yalnızca sizin verdiğiniz token ile sizin panonuza pin atar. Veriler kendi bilgisayarınızda durur, üçüncü kişiye gönderilmez.
